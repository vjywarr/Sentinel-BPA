# Sentinel-BPA (Based Population Analysis)

### A Geospatial Framework for Examining Built-Up Expansion and Population Distribution in Dehradun, Uttarakhand, India

**Author:** Vaijanti Aswal  
**Department:** Computer Science  
**Institution:** University of Petroleum and Energy Studies (UPES)  
**Location:** Dehradun, Uttarakhand, India

---

## 1. Project Overview

Sentinel-BPA is a Google Earth Engine-based geospatial analysis framework designed to examine urban expansion, built-up land changes, and population distribution across Dehradun district, Uttarakhand.

The project combines satellite imagery, built-up classification, and gridded population datasets to understand how urban growth affects population concentration and essential public-resource planning.

## 2. Technologies and Datasets

- Google Earth Engine
- JavaScript
- Sentinel-2 satellite imagery
- Dynamic World land-cover dataset
- WorldPop population estimates
- NDVI and NDBI spectral indices
- LaTeX and IEEE conference formatting
- HTML, CSS and JavaScript for the dashboard

## 3. Methodology

The project follows these major stages:

1. Study area identification and administrative boundary extraction.
2. Sentinel-2 imagery collection and preprocessing.
3. NDVI and NDBI calculation.
4. Built-up area classification for 2016 and 2025.
5. Population distribution analysis using gridded estimates.
6. Identification of high-density population zones.
7. Spatial overlay of new urban expansion and high-density areas.
8. Generation of maps, statistical outputs and visualisations.

## 4. Key Findings

The research analysis produced the following estimates:

- Net built-up area increase: 68.71 km².
- Relative built-up growth: 28.32%.
- Newly mapped built-up area: 77.47 km².
- New urban area overlapping high-density population zones: 34.37 km².
- Estimated population growth: approximately 6.74%.

These are model-derived estimates and should be interpreted according to the datasets, classification methods and assumptions used.

## 6. How to Use

**Google Earth Engine**
- Open the Google Earth Engine Code Editor.
- Import `sentinel2_analysis.js`.
- Run the analysis to reproduce the geospatial workflow.

**Research Paper**
- Upload `main.tex` and `references.bib` to Overleaf.
- Compile using the IEEE conference template.

**Dashboard**
- Download the HTML dashboard.
- Open it in a modern web browser.

Note: The dashboard is a demonstration interface. Its illustrative values should not be treated as validated research measurements.
